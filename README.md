# APS 凝血悖论研究

本项目研究高危抗磷脂抗体谱、出血表现与体外凝血酶生成受抑之间的关系。当前优先检验 IgM 组分能否转移功能效应，再追踪其中具有 PS/PT 反应性的抗体。
